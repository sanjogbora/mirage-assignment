# Quick Start Guide

## 🚀 See the Prototype in Action

### Step 1: Open the Prototype

**Easiest way:**
```bash
cd /home/user/mirage-assignment/prototype
open index.html
# Or just double-click prototype/index.html in your file browser
```

**Or with a local server:**
```bash
cd /home/user/mirage-assignment/prototype
python -m http.server 8000
# Then open: http://localhost:8000
```

### Step 2: Try These First

Once the prototype loads, try these interactions:

**Basic Navigation:**
1. **Arrow Down** → Move to "Explore Nearby"
2. **Space** → Enter that mode
3. **Escape** → Return to Home (works from anywhere!)

**Boarding Pass Demo:**
1. Click **"Boarding Pass"** quick demo button
2. See the QR code in scan mode
3. **Arrow Down** → See detailed flight info
4. **Escape** → Back to Home

**Music Player:**
1. Click **"Music Player"** quick demo
2. **Arrow Right** → Skip to next track
3. **Space** → Pause/Play
4. **Shift** → Open options menu

## 🎮 Keyboard Controls

| Key | Action |
|-----|--------|
| **Arrow Keys** | Roll ball (up/down/left/right) |
| **Space / Enter** | Single press (select) |
| **Escape** | Double press (go to Home) |
| **Shift** | Long press (options menu) |
